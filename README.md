# CodeAlpha Internship Tasks

This repository contains frontend development tasks completed as part of the CodeAlpha internship program.

## Projects

### 1. Talking Calculator (`CodeAlpha_Calculator/`)
A feature-rich calculator with voice feedback using the Web Speech API.
Supports button clicks and keyboard input with Alexa-style voice responses.

### 2. Personal Portfolio (`CodeAlpha_Portfolio/`)
A responsive personal portfolio website with smooth scrolling, loading screen
animation, typewriter effect, and scroll-reveal animations.

## Tech Stack
- HTML5
- CSS3 (animations, grid, flexbox)
- Vanilla JavaScript (Web Speech API, DOM manipulation)
